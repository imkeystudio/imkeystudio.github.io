# IMKey Studio — Portfolio Website

A responsive, static portfolio site for IMKey Studio. No build tools or paid hosting are required.

## Included
- Responsive one-page portfolio
- Dark charcoal, white, and subtle blue visual identity
- Projects marked clearly as **In development**
- CaptainCleaner (Unity 6 mobile cleaning simulator)
- Krishna-inspired action-adventure concept (Unreal Engine; pre-production)
- Services, about, and contact sections
- Mobile navigation and favicon
- Basic SEO metadata

## Preview locally
Open `index.html` in a browser. Internet is needed for Google Fonts; fallback fonts are included.

## Free deployment: GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload all files and folders from this project, keeping `index.html` at the repository root.
4. Open repository **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site address will be `https://YOUR-USERNAME.github.io/`.
   - The username and URL are examples until you confirm the handle is available.

## Alternative: Netlify
1. Sign in at https://www.netlify.com/
2. Choose Add new site / deploy manually (wording may vary).
3. Drag the project folder contents into the deploy area, or connect the GitHub repository.
4. Netlify assigns a free `*.netlify.app` subdomain; rename it in site settings if your desired subdomain is available.

## Before launch
- Confirm the GitHub username or Netlify subdomain you want.
- Replace the project artwork with your real screenshots when available.
- Check that the contact email `mkeystudio@gmail.com` is active and monitored before publishing.
- Add social profile links once those accounts are created.
- Trademark and domain availability have not been checked as part of this website package.
